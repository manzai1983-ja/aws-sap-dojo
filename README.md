# SAP-C02 合格道場

AWS Certified Solutions Architect – Professional（SAP-C02）の学習用アプリです。1つのHTMLファイルに、教科書と模擬試験が入っています。

## 内容

- **教科書（28章）**：試験ガイドの20タスク（1.1〜4.4）、補講5章（コンテナ／データ分析／AI・ML／ID連携・ハイブリッド／ID基盤：Directory ServiceとIAM Identity Center）、付録2章
  - 各章の構成：「この章の考え方」→ 場面カード（場面・困りごと・解決・メリット・注意）→ 仕組みと要点
  - 構成図11枚（ハイブリッドネットワーク、DR、マルチアカウント、移行など）と、ポリシーJSONの例
- **模擬試験（オリジナル問題95問、全問解説付き）**
  - 本番形式（75問／180分）、ミニ模試（20問）、分野別演習、苦手克服
  - 複数選択問題あり、選択肢は毎回シャッフル
- **成績・復習**：ドメイン別の正答率、受験履歴、苦手問題の一覧（ブラウザの localStorage に保存）

## 使い方

`index.html` をブラウザで開くだけで動きます。サーバーやビルドは不要です。

## 注意

- 問題と解説はすべてオリジナルです。実際の試験問題ではありません。
- 内容は2026年9月時点の SAP-C02 試験ガイドに基づいています。SAP-C02 は2026年11月に終了し、後継の SAP-C03 に移行します。
- AWSのサービス仕様は変わることがあるため、最新情報は公式ドキュメントで確認してください。
- AWS、Amazon Web Services は Amazon.com, Inc. またはその関連会社の商標です。本リポジトリはAWSとは無関係の個人の学習用資料です。
